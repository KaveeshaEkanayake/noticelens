# NoticeLens

NoticeLens explains Sinhala and English official notices in plain language, with source-verified claims.

Official notices — government circulars, legal announcements, public advisories — are often dense, written in formal register, and published only in Sinhala or English. NoticeLens bridges that gap: it parses the original notice, explains what it means in everyday language, and backs every claim with a verifiable source reference from the original document.

## What it does

- Accepts Sinhala or English official notices as input
- Extracts key facts, obligations, dates, and entities
- Explains each point in plain Sinhala and English
- Links every claim back to the exact passage in the source notice
- Flags ambiguous or potentially mistranslated sections for human review
